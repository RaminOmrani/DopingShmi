# ⚗️ دوپینگ شیمی — سایت، اپلیکیشن و پنل آموزشی استاد جواد پرتویی

سایت سینمایی + اپلیکیشن (PWA) + پنل دانش‌آموز + پنل مدیریت، روی دامنه‌ی **dopingshimi.ir**.

## 🧱 معماری

```
Next.js 16 (App Router, Turbopack) + React 19 + Tailwind CSS 4 + Motion
Prisma 7 + PostgreSQL · JWT (HttpOnly cookie) · Recharts · hls.js · sharp · ExcelJS
```
- **ویدیو**: روی ابر آروان (VOD) ذخیره و پخش می‌شود؛ سایت برای هر کاربر لینک امن انقضادار می‌گیرد. فضای سرور پر نمی‌شود.
- **عکس‌ها**: هنگام آپلود به WebP بهینه تبدیل و در `/var/lib/doping/uploads` نگه‌داری می‌شوند (مستقیم از nginx سرو می‌شوند).
- **تنظیمات** (پیامک، آروان، درگاه، امتیازها، متن‌های سایت) در دیتابیس ذخیره و از پنل مدیریت ویرایش می‌شوند.

## 🚀 نصب روی سرور (Ubuntu 24.04)

۱. رکورد **A** دامنه‌ی `dopingshimi.ir` (و `www`) را روی IP سرور تنظیم کنید.
۲. با کاربر root:
```bash
curl -fsSL https://raw.githubusercontent.com/RaminOmrani/DopingShmi/claude/dazzling-meitner-g7mbwp/deploy/install.sh -o install.sh
bash install.sh dopingshimi.ir
```
اسکریپت همه‌چیز را نصب می‌کند: Node.js 22، PostgreSQL، nginx، pm2، گواهی SSL، فایروال و پشتیبان‌گیری روزانه.

۳. ورود مدیر: `https://dopingshimi.ir/login` ← «ورود مدیر با رمز عبور»
   - شماره: `09158148172` · رمز اولیه: `doping1234` ← **فوراً از تنظیمات تغییر دهید**

| دستور | کاربرد |
|---|---|
| `bash /opt/doping/deploy/update.sh` | به‌روزرسانی به آخرین نسخه |

## ✅ چک‌لیست راه‌اندازی (بعد از نصب)

1. **تنظیمات ← پیامک**: کلید API ملی‌پیامک + شماره خط ← «ذخیره و بررسی اعتبار» ← پیامک آزمایشی. IP سرور را در پنل ملی‌پیامک مجاز کنید.
2. **پیامک ← الگوها**: متن هر الگو را در ملی‌پیامک ثبت و کد الگو را وارد کنید (پایین‌تر).
3. **تنظیمات ← ویدیو (آروان)**: کلید API ← «ذخیره و تست اتصال».
4. **تنظیمات ← درگاه**: مرچنت زرین‌پال ← ابتدا با حالت آزمایشی تست کنید.
5. **عکس‌ها**: عکس اصلی استاد (بخش «عکس اصلی استاد»، ترجیحاً PNG دوربری‌شده) + عکس‌های همایش‌ها.
6. **رتبه‌های برتر** و **متن‌های سایت** را بررسی کنید.
7. **کلاس‌ها**: کلاس‌ها/آموزشگاه‌ها را تعریف کنید تا دانش‌آموزان هنگام ثبت‌نام انتخاب کنند.
8. **مباحث و ویدیوها**: فصل‌های کتاب از قبل ساخته شده‌اند؛ ویدیوها را اضافه و قیمت‌ها را تنظیم کنید.

## 🎬 ویدیو روی ابر آروان

1. پنل آروان ← **پلتفرم ویدیو** ← ساخت کانال (مثلاً `doping`).
2. در تنظیمات کانال **لینک امن (Secure Link)** را فعال کنید.
3. پنل کاربری ← **کلیدهای API** ← کلید با دسترسی ویدیو بسازید و در «تنظیمات ← ویدیو» وارد کنید.
4. ویدیو را در کانال آپلود کنید؛ پس از پردازش، **شناسه‌ی ویدیو (Video ID)** را کپی و در «مباحث و ویدیوها ← افزودن ویدیو» وارد کنید. مدت ویدیو خودکار خوانده می‌شود.

محافظت: لینک پخش برای هر کاربر جدا و با تاریخ انقضا ساخته می‌شود (قابل اشتراک نیست)، شماره‌ی موبایل کاربر به‌صورت متحرک روی ویدیو نمایش داده می‌شود و دکمه‌ی دانلود پلیر غیرفعال است. قفل روی IP هم در تنظیمات قابل فعال‌سازی است.

## 📝 آزمون‌های پلکان (بدون API)

پلکان API نمی‌دهد؛ برای همین روند این‌طور طراحی شده:
1. استاد آزمون را در **آزمون‌ساز دبیر پلکان** می‌سازد و لینکش را در «آزمون‌ها ← آزمون جدید ← آزمون پلکان» وارد می‌کند (با مخاطب، پایه، رشته، کلاس و بازه‌ی زمانی).
2. دانش‌آموز از داخل سایت/اپ روی «ورود به آزمون» می‌زند؛ شرکت او ثبت می‌شود و پلکان باز می‌شود (در صفحه‌ی جدید، یا داخل سایت اگر پلکان اجازه دهد).
3. پس از آزمون، استاد **خروجی اکسل کارنامه** را از پلکان می‌گیرد و در تب «ورود نتایج» آپلود می‌کند. ستون‌ها (موبایل، نام، درصد/نمره، تراز، رتبه) خودکار تشخیص داده می‌شوند؛ دانش‌آموزان با شماره موبایل یا نام کامل پیدا می‌شوند و موارد پیدانشده گزارش می‌شوند. ثبت دستی نمره هم ممکن است.
4. نتایج بلافاصله در کارنامه، نمودار پیشرفت، رتبه‌بندی و امتیاز دانش‌آموز اعمال می‌شود؛ با یک دکمه پیامک نتیجه برای دانش‌آموزان (و والدین) ارسال می‌شود.

علاوه بر پلکان، **آزمون تستی داخل سایت** هم وجود دارد که کاملاً خودکار تصحیح می‌شود.

## 📲 ساخت اپلیکیشن با PWABuilder

1. بعد از بالا آمدن سایت روی **https**، به [pwabuilder.com](https://www.pwabuilder.com) بروید و `https://dopingshimi.ir` را وارد کنید (manifest، آیکون‌ها و service worker آماده‌اند).
2. **Package for stores ← Android**؛ Package ID مثلاً `ir.dopingshimi.app`.
3. فایل `assetlinks.json` که PWABuilder می‌دهد را در `public/.well-known/assetlinks.json` قرار دهید و `update.sh` را اجرا کنید تا نوار آدرس در اپ دیده نشود.
4. فایل APK/AAB را برای بازار/مایکت یا نصب مستقیم منتشر کنید.

## 💻 اجرای محلی (توسعه)

```bash
pnpm install
cp .env.example .env         # DATABASE_URL را تنظیم کنید
pnpm db:push
pnpm db:seed -- --demo       # داده‌ی نمایشی (دانش‌آموز نمونه: 09150001000)
pnpm dev
```
در حالت آزمایشی پیامک، کد ورود در اعلان صفحه نمایش داده می‌شود.
